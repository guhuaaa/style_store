# Ukiyo-e / 浮世绘 — Style DNA

## Historical Definition
c. 1670–1900；本目录只将其作为有明确艺术史与设计史语境的 `ART_HISTORY_STYLE` 管理。

## Core DNA
- `flat color planes` — CORE
- `cropped viewpoint` — CORE
- `directional wave or contour rhythm` — CORE
- `asymmetric negative space` — CORE

## Secondary DNA
- `indigo-led limited palette` — SECONDARY
- `woodblock line and pattern` — SECONDARY

## Composition
将视觉重心、轴线、留白和边缘处理视作风格的第一载体；不以名称或色板替代构图。

## Shape / Line / Rhythm
形状、线条连续性、重复节奏必须共同对应核心规则；预览中应能从版式而非标题辨认。

## Color / Typography / Surface / Ornament
颜色承担层级或区隔功能；字体、纹理与装饰只在不损害可读性时服务结构。

## Common Misinterpretations
日式图标或单一海浪纹样不等于浮世绘；需采用平面色块、裁切视角、轮廓节奏与留白。

## Evidence policy
每个 CORE 规则应在上述至少一个历史参考中得到复核；网络参考仅用于本地研究，必须保留 URL、采集时间和许可状态。
