# Expressionism / 表现主义 — Style DNA

## Historical definition
c. 1905–1920; an art-historical style, not a surface theme.

## Core references
- [MoMA — Expressionism](https://www.moma.org/collection/terms/expressionism/responding-to-the-anxiety-of-modern-life)
- [MoMA — Expressionism collection](https://www.moma.org/collection/works?classification=Paintings&theme=Expressionism)
- [Tate — Expressionism](https://www.tate.org.uk/art/art-terms/e/expressionism)

## Core DNA
- `emotionally charged color contrast` — CORE
- `acute directional tension` — CORE
- `intentionally distorted planes` — CORE
- `bold graphic silhouette` — CORE

## Secondary DNA
- `high-contrast non-natural color` — SECONDARY
- `dark structural contour` — SECONDARY

## Anti-mimicry rule
