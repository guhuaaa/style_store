# Suprematism / 至上主义 — Style DNA

## Historical definition
from 1915; an art-historical style, not a surface theme.

## Core DNA
- `non-objective floating geometry` — CORE
- `weightless white field` — CORE
- `independent geometric hierarchy` — CORE
- `off-axis spatial balance` — CORE

## Secondary DNA

- `absence of enclosing grid` — SECONDARY
