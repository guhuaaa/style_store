# Post-Impressionism / 后印象派 — Style DNA

## Historical definition
c. 1886–1905; an art-historical style, not a surface theme.

## Core references
- [The Met — Post-Impressionism overview](https://www.metmuseum.org/toah/hd/poim/hd_poim.htm)
- [The Met — Post-Impressionism collection search](https://www.metmuseum.org/art/collection/search#!?q=Post-Impressionism)
- [Tate — Post-Impressionism](https://www.tate.org.uk/art/art-terms/p/post-impressionism)

## Core DNA
- `constructed color masses` — CORE
- `expressive contour or faceting` — CORE
- `deliberate flattening of depth` — CORE
- `rhythmic color-led grouping` — CORE

## Secondary DNA
- `saturated but organized color` — SECONDARY
- `structural brush-like segmentation` — SECONDARY

## Anti-mimicry rule
Do not reduce to an arbitrary bright palette or generic painterly noise.
