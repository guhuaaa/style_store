# Dada / 达达主义 — Style DNA

## Historical definition
c. 1916–1924; an art-historical style, not a surface theme.

## Core references
- [MoMA — Dada](https://www.moma.org/collection/terms/dada)
- [Tate — Dada](https://www.tate.org.uk/art/art-terms/d/dada)
- [The Met — Dada collection search](https://www.metmuseum.org/art/collection/search#!?q=Dada)

## Core DNA
- `deliberate collision of found forms` — CORE
- `disrupted type–image relationship` — CORE
- `chance-like but curated juxtaposition` — CORE
- `ironic scale shift` — CORE

## Secondary DNA
- `print, cut-paper, and ink contrast` — SECONDARY
- `limited disruptive accent color` — SECONDARY
