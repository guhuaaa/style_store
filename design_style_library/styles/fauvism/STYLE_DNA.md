# Fauvism / 野兽派 — Style DNA

## Historical definition
c. 1905–1910; an art-historical movement, not a surface theme.

## Core references
- [The Met — Fauvism](https://www.metmuseum.org/toah/hd/fauv/hd_fauv.htm)
- [Tate — Fauvism](https://www.tate.org.uk/art/art-terms/f/fauvism)
- [MoMA — Henri Matisse](https://www.moma.org/artists/3832)

## Core DNA
- `non-natural high-chroma color blocks` — CORE
- `simplified emphatic contour` — CORE
- `flat decorative depth` — CORE
- `color-led grouping` — CORE

## Secondary DNA
- `warm-cool collisions` — SECONDARY
- `economical broad marks` — SECONDARY
