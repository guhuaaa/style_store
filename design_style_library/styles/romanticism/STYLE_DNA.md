# Romanticism / 浪漫主义 — Style DNA

## Historical definition
c. 1800–1850; an art-historical style, not a surface theme.

## Core references
- [The Met — Romanticism](https://www.metmuseum.org/essays/romanticism)
- [The Met — Romanticism collection search](https://www.metmuseum.org/art/collection/search#!?q=Romanticism)
- [Tate — Romanticism](https://www.tate.org.uk/art/art-terms/r/romanticism)

## Core DNA
- `sublime scale contrast` — CORE
- `atmospheric depth` — CORE
- `diagonal weather or light movement` — CORE
- `small human-scale focal point` — CORE

## Secondary DNA
- `luminous dusk and storm color` — SECONDARY
- `soft-to-sharp depth transitions` — SECONDARY

## Anti-mimicry rule
Do not reduce to a dark scenic backdrop or an emotional poster.
