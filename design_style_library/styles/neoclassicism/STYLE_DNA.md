# Neoclassicism / 新古典主义 — Style DNA

## Historical definition
c. 1760–1850; an art-historical style, not a surface theme.

## Core references
- [The Met — Neoclassicism overview](https://www.metmuseum.org/toah/hd/neoc/hd_neoc.htm)
- [The Met — Neoclassical art collection search](https://www.metmuseum.org/art/collection/search#!?q=Neoclassicism)
- [National Gallery — Neoclassicism](https://www.nationalgallery.org.uk/paintings/learn-about-art/neoclassicism)

## Core DNA
- `disciplined bilateral order` — CORE
- `columnar and rectilinear rhythm` — CORE
- `measured proportions` — CORE
- `restrained civic gravity` — CORE

## Secondary DNA
- `stone, ink, muted red accents` — SECONDARY
- `crisp contour and generous margins` — SECONDARY

## Anti-mimicry rule
Do not reduce to Greek-key borders, gold ornament, or institutional stiffness.
