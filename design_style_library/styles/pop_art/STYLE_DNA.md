# Pop Art / 波普艺术 — Style DNA

## Historical Definition
c. 1950s–1970s；本目录只将其作为有明确艺术史与设计史语境的 `ART_HISTORY_STYLE` 管理。

## Core References
- MoMA — Pop Art term: https://www.moma.org/collection/terms/pop-art
- MoMA — Andy Warhol collection: https://www.moma.org/artists/6246
- The Met — Pop Art essay: https://www.metmuseum.org/toah/hd/pop/hd_pop.htm

## Core DNA
- `commercial-image language` — CORE
- `high-key contrast` — CORE
- `repetition as rhythm` — CORE
- `scale jump and crop` — CORE

## Secondary DNA
- `halftone field` — SECONDARY
- `speech-bubble framing` — SECONDARY

## Composition
将视觉重心、轴线、留白和边缘处理视作风格的第一载体；不以名称或色板替代构图。

## Shape / Line / Rhythm
形状、线条连续性、重复节奏必须共同对应核心规则；预览中应能从版式而非标题辨认。

## Color / Typography / Surface / Ornament
颜色承担层级或区隔功能；字体、纹理与装饰只在不损害可读性时服务结构。

## Common Misinterpretations
鲜艳颜色本身不等于波普；重复、商品化图像语言、裁切和夸张比例才是核心。

## Evidence policy
每个 CORE 规则应在上述至少一个历史参考中得到复核；网络参考仅用于本地研究，必须保留 URL、采集时间和许可状态。
