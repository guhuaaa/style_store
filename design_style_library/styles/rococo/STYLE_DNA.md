# Rococo / 洛可可 — Style DNA

## Historical definition
c. 1730–1770; an art-historical style, not a surface theme.

## Core references
- [The Met — Rococo art overview](https://www.metmuseum.org/toah/hd/roco/hd_roco.htm)
- [The Met — European decorative arts](https://www.metmuseum.org/art/collection/search#!?department=12)
- [V&A — Rococo](https://www.vam.ac.uk/articles/rococo-style)

## Core DNA
- `airy asymmetrical balance` — CORE
- `shell-like curvilinear rhythm` — CORE
- `delicate ornamental flow` — CORE
- `lightness around the focal content` — CORE

## Secondary DNA
- `powdered pastel relationships` — SECONDARY
- `fine, low-contrast detail` — SECONDARY

## Anti-mimicry rule
Do not reduce to pink gradients, generic florals, or decorative excess that harms reading.
