# Cubism / 立体主义 — Style DNA

## Historical definition
c. 1907–1914; an art-historical style, not a surface theme.

- [MoMA — Cubism](https://www.moma.org/collection/terms/cubism)

## Core DNA
- `simultaneous viewpoints` — CORE
- `interlocking faceted planes` — CORE
- `shallow assembled space` — CORE
- `fragmented but legible hierarchy` — CORE

## Secondary DNA
- `earthy neutrals with selective color` — SECONDARY
- `collage-like material distinction` — SECONDARY
