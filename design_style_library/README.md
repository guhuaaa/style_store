## 资产与来源政策

每个外部参考均记录来源 URL、抓取时间、许可状态和本地研究用途。网络图像仅用于设计研究、视觉检索与参考，不作为自有商业资产发布。

项目原创渲染预览使用 HTML/CSS/SVG 生成并由本地浏览器输出为 PNG；AI 预览单独标记其生成方式和验证状态。
