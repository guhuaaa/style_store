# Style Store｜艺术史前端风格库

一个面向前端设计、视觉提示词和 AI 生成工作流的艺术史风格库。

本库收录 32 种艺术史风格，每种风格提供：

- 风格名称
- 风格 ID
- 前端提示词
- 图像提示词
- 前端预览图
- 概述预览图

## Live Demo

👉 **打开完整风格汇总页：**
https://guhuaaa.github.io/style_store/

## 用法

把库下载到codex等工具可以访问的项目目录下，你可以在项目设计时直接复制对应风格的提示词，例如：

```text
选择包豪斯风格，落地这个项目的前端
```

适合场景
前端视觉风格探索
AI 产品原型设计
README / 作品集展示
Prompt 风格库整理
艺术史风格迁移到 UI 设计
